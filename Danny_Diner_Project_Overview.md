# Danny's Diner SQL Case Study

## Project Objective
Analyze restaurant sales data to understand
customer purchasing behaviour.

## Tools Used
- MySQL
- SQL

## Dataset
- Sales
- Menu
- Members

## SQL Concepts
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- Aggregate Functions

## Business Questions
1. How much did each customer spend?
2. How many days did each customer visit?
3. What was the most popular item?
4. What was the first purchased item?
5. What are the total sales?
